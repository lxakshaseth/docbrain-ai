DocBrain AI • Executive Summary

Executive Summary & Core Value Proposition

🎯 The Challenge
  • Traditional search fails on unstructured multi-page PDF documents.
  • Monolithic AI backends cause CPU/Memory bottlenecks on HTTP API routes.
  • Pure vector search suffers from hallucination without exact keyword precision.
  • Requirement for secure multi-tenant authorization and document boundaries.
🚀 The Solution
  • Decoupled Event Architecture: Redis Pub/Sub eliminates backend HTTP waiting.
  • Hybrid RAG Engine: Combines ChromaDB Vector Search + BM25 Sparse Keyword Search via Reciprocal Rank Fusion.
  • LangGraph StateGraph Workflow: Multi-step pipeline with self-correcting grounded answers & auto-generated follow-ups.
  • Full AI Study Suite: Summaries, interactive mind maps, flashcards, and gTTS audio overviews.

DocBrain AI • Event Driven

Mandatory Redis Event Broker Architecture

📡 Redis Event Channels
  • pdf:ingest:request - Node backend publishes upload metadata.
  • pdf:ingest:response - Python service returns ingestion status & chunk metrics.
  • rag:query:request - Node publishes prompt payload & chat session ID.
  • rag:stream:chunk - Token-by-token pub/sub streaming to Node SSE handler.
🛡️ System Advantages
  • Non-blocking API: Node.js HTTP event loop remains responsive under high load.
  • Independent Scaling: Python AI workers scale independently based on vector load.
  • Fault Isolation: AI crashes do not affect web authentication or user databases.
  • Zero HTTP Wait: Mandatory microservice decoupling principle enforced.
DocBrain AI • AI Engine

LangGraph StateGraph RAG Pipeline

STEP 1: hybrid_retrieve
  • Queries ChromaDB Dense Embeddings.
  • Queries Sparse BM25 Keyword Index.
  • Fuses rank scores using Reciprocal Rank Fusion.
  • Retrieves top-k grounded snippets.
STEP 2: generate_answer
  • Injects strict anti-hallucination prompt.
  • Loads conversation history memory.
  • Invokes Groq Llama-3.1-70b / Gemini.
  • Enforces exact document attribution.
STEP 3: generate_followups
  • Parses answer and retrieved context.
  • Generates 3 logical follow-up prompts.
  • Returns structured JSON to client.
  • Drives interactive exploration.
DocBrain AI • Retrieval Engine

Hybrid Search Engine: BM25 + ChromaDB Vector RRF

🧠 Search Mechanics
  • ChromaDB Dense Vectors: Captures high-level semantic intent & contextual concepts.
  • Sparse BM25 Keyword Search: Matches technical codes, formulas, proper nouns, and exact text.
  • Reciprocal Rank Fusion (RRF): Merges rankings smoothly without requiring score normalization.
🎯 Accuracy & Reliability
  • Zero-Context Fallback: Rejects prompts outside PDF content scope.
  • Exact Citation: Every answer provides page numbers and text offsets.
  • Recursive Text Splitter: 1000 chunk size with 200 character overlap.

DocBrain AI • Security

Security, Auth & Data Integrity

🔐 JWT Auth & RBAC
  • Stateless JSON Web Tokens.
  • Bcrypt password hashing.
  • RBAC middleware enforcing document user boundaries.
🛡️ DTO Validation
  • Zod schemas on all Express HTTP endpoints.
  • Pydantic schemas on Redis Pub/Sub messages.
  • Sanitized input streams.
📁 File & Vector Isolation
  • Multer file upload MIME type validation.
  • Isolated vector namespaces per user.
  • Zero cross-tenant vector leakage.
